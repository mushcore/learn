## The tie-breaker as the slides apply it (module convention)
- "Deepest inside the loop" (slide 27) is read as **loop depth**: count the loops that enclose a line. A loop's own test (`for` / `while` line) and an `if` condition count as inside that loop, at the same depth as its body; an `if` does not add depth.
- Lines at the same loop depth with the same count go to slide 41's list (cost). This reproduces both of the lecture's own picks: find's line 4 over lines 3 and 5 (slide 28/49/82) and Loops' line 5 over lines 6-7 (slide 37).
- Loop tests are counted once per iteration (slides 25-27 count find's line 3 as n − 1, not n). Under that convention the countdown fragment's line 7 (`while x > 0`) ties line 8 at 15 for n = 10 (19 with the exit tests); line 8 wins on cost because `x > 0` is a simple numerical comparison, not a data comparison (slide 37).
