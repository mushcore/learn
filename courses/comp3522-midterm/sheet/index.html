C. Definitions in three moves

Q1 Copy ctor (4). Builds a new object from an existing one: Fraction(const Fraction& other) (by value would recurse). Runs on T b(a); T b = a; pass/return by value; not b = a; Default is shallow.

Q2 Reference vs pointer (3). Reference: an alias, another name for a variable; initialized at once, never re-seated: int& r = n; Pointer: holds an address; may be null or re-pointed: int* p = &n;

Q3 Pass by (4). Value copies (caller safe). Pointer passes the address (changes the pointee; may be nullptr). Reference: no copy, changes the caller's variable; const T& for big objects.

Q4 (4). *success: the string, to read or change it. &success: the pointer's own address (string**), so a function can re-point it: void reset(string** pp).

Q5 Static vs dynamic (4). Static: int x = 5; stack, compile-time size, freed at }. Dynamic: int* p = new int[n]; heap, run-time size, until delete[] p;

Q6 Leak (4). new memory never deleted: unreachable until exit. Prevent: pair new/delete; free in the destructor. void leak() { int* p = new int[100]; delete[] p; }

Q7 const (6). a. void print(const Fraction& f): will not modify the argument (with &: no copy). b. int getNumerator() const; changes no member; callable on a const object.

Q8 Destructor (3) at end of scope (and unwinding), on delete, a temporary at its ;, members and bases after the body, statics at exit. Reverse order.

Q9 Init (4). int x = 0; int x(0); int x{0}; Prefer braces: no narrowing (int y{3.7}; won't compile; others truncate).

Q10 (2). :: scope resolution: std::cout, Fraction::Fraction(…) outside the class. . a member of an object; -> through a pointer.

Q11 class vs struct (2). Only default access: struct public, class private (members, inheritance).

Q12 Forward declaration (3). class Car; before the definition: Car*, Car& usable (mutual references, fewer includes); Car c; is incomplete.

Q13 Abstract (3). At least one pure virtual: virtual double area() const = 0; No keyword; cannot instantiate; derived stays abstract until all are overridden.

Q14 Interface (2). No keyword: a pure abstract class (only pure virtuals, a virtual destructor), inherited.

Q15 Diamond (6). a. student, mathematician inherit person; math_student both: two persons unless virtual. b. bob.all_info() ambiguous: bob.mathematician::all_info() or override. c. Most-derived calls person(name); middle calls ignored.

Q16 Copy-and-swap (3). T& operator=(T other): 1. by-value copy 2. mySwap every member 3. other dies with the old data. Errors: a T& parameter; std::swap on the whole object (recurses).

#include <iostream> <fstream> <sstream> <stack> <vector> <algorithm> <stdexcept> <string> (one per line); using namespace std;

class Fraction {
private:
  int numerator;
  int denominator;
public:
  // Q21: initializer list, then the check
  Fraction(int numerator, int denominator)
    : numerator(numerator),
      denominator(denominator) {
    if (denominator == 0)
      throw invalid_argument(
        "Denominator cannot be zero");
  }
  // Q22: const &, else it would recurse
  Fraction(const Fraction& other)
    : numerator(other.numerator),
      denominator(other.denominator) {}
  ~Fraction() {}  // Q23: nothing to free
  int getNumerator() const {
    return numerator; }
  // Q24: write to os, return os
  friend ostream& operator<<(
      ostream& os, const Fraction& f) {
    os << f.numerator << "/"
       << f.denominator;
    return os; }
  // Q25: read into f, return is
  friend istream& operator>>(
      istream& is, Fraction& f) {
    is >> f.numerator >> f.denominator;
    return is; }
  friend Fraction operator+(
      const Fraction& a, const Fraction& b)
  { return Fraction(
      a.numerator * b.denominator
        + b.numerator * a.denominator,
      a.denominator * b.denominator); }
  friend bool operator==(
      const Fraction& a, const Fraction& b)
  { return a.numerator * b.denominator
      == b.numerator * a.denominator; }
  friend bool operator<(
      const Fraction& a, const Fraction& b)
  { return a.numerator * b.denominator
      < b.numerator * a.denominator; }
};

F. Deep copy, copy-and-swap, abstract, interface, diamond

class Character {
  int* skillIds;
  int size;
public:
  Character(int n)
    : skillIds(new int[n]{}), size(n) {}
  Character(const Character& o)  // deep
    : skillIds(new int[o.size]),
      size(o.size) {
    for (int i = 0; i < size; ++i)
      skillIds[i] = o.skillIds[i]; }
  ~Character() { delete[] skillIds; }
  friend void mySwap(Character& a,
                     Character& b) {
    swap(a.skillIds, b.skillIds);
    swap(a.size, b.size); }  // all members
  Character& operator=(Character other)
  { // 1. by value: copy ctor made other
    mySwap(*this, other);  // 2. swap all
    return *this; }  // 3. other dies: old
};
