# MapleStory Classic World fact bank

Covers Nexon's official **Global MapleStory Classic World**: Nexon's own pre-Big Bang style world, run by Nexon America on nexon.com and played through the Nexon Launcher or Steam. Its region is Global, and English is the official language. Founder's Access opened 2026-10-06 and the Grand Launch was 2026-10-21. The live version is the Grand Launch build: Maple Island and Victoria Island, 1st and 2nd job only, level cap Lv. 100. It has no public patch number, so entries cite the Grand Launch Release Notes (posted 2026-10-20). Checked on 2026-10-27. Official facts come from Nexon's MapleStory news posts and Nexon's Cash Shop rate pages. Nexon publishes no scroll rates, monster stats or EXP/meso/drop rates for Classic World, so those entries come from the fan database meowdb.com ("NiaMeowDB", not affiliated with Nexon), and each is marked `Trust: wiki`. meowdb shows no client version number. Its item pages carry a change history (for example the Chaos scroll, item 135, "updated in COT2": COT1 was INT +5 with 100% destroy on failure, COT2 is INT +4 with 50%), so item entries say that the item text was last changed in COT2 and are dated by the day the page was read. This is not a private server. Nexon's own 2026-09-11 post "Notice Regarding Unauthorized MapleStory Servers" is about private servers.

| Region | Global |
| Clients | Nexon Launcher (standalone client) or Steam (bundled with MapleStory) |
| Platforms | Windows and macOS |
| Languages | English (official), Spanish (Beta), Korean (Beta) |
| Characters per account | up to 3 |
| Maximum character level | Lv. 100 |
Source: https://www.nexon.com/maplestory/news/general/46506 (Nexon). Version: Grand Launch Release Notes, posted 2026-10-20, for the 2026-10-21 6:00 PM UTC launch. Checked: 2026-10-27. Trust: official.

New accounts have a trade restriction: "All trading features will become available 24 hours after a character on the account reaches Lv. 15."

### classic.scroll.tiers
Each Classic World scroll family comes in four tiers. Lesser always succeeds, Intermediate succeeds 60% of the time, Greater 10%, and Chaos 10% with a 50% chance that a failure destroys the item.
| Tier | Success rate | Destroyed on failure | Example: Overall Armor INT |
|---|---|---|---|
| Lesser | 100% | no | INT +1 |
| Intermediate | 60% | no | INT +2 |
| Greater | 10% | no | INT +3 |
| Chaos | 10% | 50% | INT +4 |
Source: https://meowdb.com/msclassic/item-db/145 (meowdb.com, fan database). Version: MapleStory Classic World item text last changed in COT2 per meowdb change history, no change listed in meowdb's patch log through 2026-10-22; page read 2026-10-27. Checked: 2026-10-27. Trust: wiki.
Notes: Item 145 ("Overall Armor INT Scroll: Intermediate") carries the in-game text "Improves Intelligence on overalls. Success rate: 60%, INT +2". The other tiers of the same family: item-db/150 (Lesser, "Success rate: 100%, INT +1"), item-db/140 (Greater, "Success rate: 10%, INT +3"), item-db/135 (Chaos, "Success rate: 10%, INT +4 / Upon failure, the item has a 50% chance to be destroyed."). All 208 scrolls in meowdb ids 1-208 follow this pattern, 52 per tier (dataset classic.data.scrolls). Classic World does NOT use old-GMS "10% / 60% / 100%" names or 30% / 70% dark scrolls. Each tier's rate is fixed and attempts are independent, so Intermediate (p = 0.6) and Greater (p = 0.1) suit binomial and geometric work; Lesser is a 100% control case. Equipment shows its slots as "Available Enhancements" (e.g. the event Pumpkin Basket has "Available Enhancements: 7", per Nexon's Grand Launch notes).

### classic.scroll.chaos-outcomes
A Chaos scroll has three outcomes per use: success (10%), failure with the item kept, or failure with the item destroyed (a failure destroys the item 50% of the time).
| Outcome | Probability |
|---|---|
| Success (stat added) | 10% |
| Fail, item kept | 90% × 50% |
| Fail, item destroyed | 90% × 50% |
Source: https://meowdb.com/msclassic/item-db/135 (meowdb.com, fan database). Version: MapleStory Classic World item text last changed in COT2 per meowdb change history, no change listed in meowdb's patch log through 2026-10-22; page read 2026-10-27. Checked: 2026-10-27. Trust: wiki.
Notes: The page text is "Success rate: 10%, INT +4 / Upon failure, the item has a 50% chance to be destroyed." The table's second and third rows are the tree that wording implies, which makes this a tree-diagram and conditional-probability exercise: P(destroyed | failed) = 0.5. Lessons should do the multiplication (0.45 each) as the exercise.

### classic.scroll.stat-ladders
The stat a scroll adds depends on its family as well as its tier. HP/MP scrolls give +10/+15/+20/+25, weapon-attack scrolls +1/+2/+4/+5, and staff/wand magic-attack scrolls +2/+4/+8/+10.
| Family (example item) | Lesser 100% | Intermediate 60% | Greater 10% | Chaos 10% |
|---|---|---|---|---|
| Overall Armor STR/DEX/INT/LUK | +1 | +2 | +3 | +4 |
| Hat / Topwear HP (Max HP) | +10 | +15 | +20 | +25 |
| Polearm / Spear Attack (Weapon Attack) | +1 | +2 | +4 | +5 |
| Staff / Wand Magic Attack | +2 | +4 | +8 | +10 |
| Overall / Topwear / Shield DEF | W.Def +2 | W.Def +4, M.Def +2 | W.Def +6, M.Def +4 | W.Def +8, M.Def +6 |
Source: https://meowdb.com/msclassic/item-db/122 (meowdb.com, fan database). Version: MapleStory Classic World item text last changed in COT2 per meowdb change history, no change listed in meowdb's patch log through 2026-10-22; page read 2026-10-27. Checked: 2026-10-27. Trust: wiki.
Notes: Item 122 is "Hat HP Scroll: Chaos": "Success rate: 10%, Max HP +25". The other cells are item-db 125/128/131 (Hat HP), 161-164 (Polearm), 185-188 (Spear), 189-192 (Staff), 205-208 (Wand), 133/138/143/148 (Overall DEF). Every row is in classic.data.scrolls. This is an expected-value table: E = p × gain per slot. For HP scrolls Lesser (+10) beats Intermediate (0.6 × 15); for primary stats Intermediate (0.6 × 2) beats Lesser (+1). Lessons compute these themselves.

### classic.formula.damage-roll
meowdb's Classic World damage formula draws a base multiplier B uniformly between 0.8 and 1.0 on every hit, and a stat term Q uniformly between Primary × Mastery and Primary.
Source: https://meowdb.com/msclassic/formulas/damage (meowdb.com, fan database). Version: MapleStory Classic World formulas page, read 2026-10-27, no version shown. Checked: 2026-10-27. Trust: wiki.
Notes: The page text is "B = uniform(0.8, 1.0)", "Q = uniform(Primary × M, Primary)", "M = (MasteryLevel / 10 + 0.1) × 0.7". The page calls these "Raw formulas used across MeowDB's Classic tools". They are reconstructed by the fan site, not published by Nexon. Use B alone as the uniform example. The final damage number is a combination of two uniform draws, so it is NOT itself uniform between MIN and MAX. Do not teach it as uniform.

## Unverified

- **Old-GMS scroll names (10% / 60% / 100% / 30% / 70% dark scrolls).** These do not exist in Classic World. The live game uses four tiers: Lesser 100%, Intermediate 60%, Greater 10%, and Chaos 10% with 50% destroy on failure (classic.scroll.tiers). All 208 scrolls on meowdb, and the scrolls named in Nexon's Grand Launch notes ("...: Intermediate", "...: Greater"), use these names. No 30% or 70% scroll exists, so none was entered.
- **EXP / meso / drop rate multipliers.** Nexon has published none for Classic World. The posts read were news ids 39217, 40017, 43432, 43808, 45385, 45490, 45621, 45681, 45819, 46362, 46370, 46506, 46730 and 47102: the FAQ, release notes for both tests, Founder's Access and Grand Launch, the cash shop posts, and Inkwell's letter. None of them gives a rate. Only the 1.5x / 2x 15-minute EXP coupons exist as items (meowdb item-db/233, 234), which is not a server rate.
- **Official scroll success rates from Nexon.** No Nexon page states them. The rates above come from the in-game item text as shown on meowdb (Trust: wiki).
- **Monster drop rates and any count-per-hour (Poisson) data.** I found none with a sample size. meowdb monster pages show only community "seen it drop" votes and OSMLib (old MapleSEA) reference rates, which the site itself says "may not represent MapleStory Classic World rates". Nexon gives event drops only as "a chance" (Maple Leaf, Halloween Candies). Respawn timers on meowdb (~7.5s) are fixed timers, not Poisson.
- **Classic World ranking / level dataset.** Not found. Nexon's ranking API (https://www.nexon.com/api/maplestory/no-auth/ranking/v2/na) returns modern GMS worlds only. The nexon.com site bundle has Classic routes for world map, classes and explore pages, but none for rankings.
- **Ossyria / 3rd job timing.** The 3rd job at Lv. 70 was live only in Closed Online Test #2. The official "Ossyria Exploration Report" (news/general/44359, 2026-08-21) is published as images only, so its text could not be read. Release timing after launch is unsourced.
